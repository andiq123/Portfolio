# Andrei Ungureanu — Portfolio

Personal software engineering portfolio built with Next.js, React, TypeScript, Tailwind CSS, and Framer Motion.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint
npm run build
npm audit
```

The resume is served from `public/resume.pdf`. Project content lives in `src/data/datastore.ts`.
